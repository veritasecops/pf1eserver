# Theme assets

The medieval theme takes its color and art direction from https://paizo.com/pathfinder.
No Paizo illustrations, logos, or fonts are bundled or hotlinked.

`citadel-dusk.jpg` and `parchment.jpg` are original images created for this project
with the built-in imagegen tool, then converted to JPEG for delivery. Both are
served locally and remain compatible with the application's existing CSP.

## Citadel prompt

Use case: stylized-concept. Asset type: wide background illustration for a medieval fantasy tabletop roleplaying web application named Pathkeeper. Primary request: an original hand-painted epic fantasy landscape, an ancient fortified citadel with weathered towers on a crag above a misty valley, winding pilgrim road, distant jagged mountains and a tiny red dragon silhouette far in the sky. No recognizable existing characters, no logos, no lettering. Composition: cinematic wide landscape, fortress on the right third, atmospheric unobtrusive darker sky and mountains on the left to support overlaid cream text. Lighting: warm amber dusk breaking through smoky clouds, subtle embers, rich painterly detail, traditional fantasy book-cover illustration rather than photorealism or modern 3D. Palette: oxblood crimson, dark umber, antique gold, warm parchment, charcoal; muted forest green in the valley. Full bleed, no frame, no typography or UI. Intended background with legible overlay; avoid busy high-contrast foreground objects on left. Landscape 1536x1024 or wider.

## Parchment prompt

Use case: stylized-concept. Asset type: seamless aged parchment background texture for a readable medieval fantasy web application. Primary request: a flat, evenly lit, warm ivory and pale sand vellum sheet texture, very subtle organic fibers, delicate warm honey mottling. Uniform full-bleed surface, tileable in both directions, no visible page edges, no dark border, no isolated stains, no strong shadows, no folds, no objects, no writing, no symbols, no ornament, no text. Extremely low contrast for small dark body text over it. Palette warm cream ivory #f2e5c6, light tan #e9d5ab. Square texture 1024x1024.
