## Campaign lists

Campaigns lists the worlds you own or have joined. Admins see every campaign. Players can open joined campaigns but cannot create or edit them. Game Masters can create and manage their own campaigns, while memberships in other campaigns provide ordinary joined access.

## Create and edit

As a GM or Admin, select **Create campaign**. Enter a name, setting/world, and description. GMs become the owner of campaigns they create. An Admin can select an active GM or Admin as owner.

Use **Edit campaign** to update those fields. Admins can transfer ownership to another active GM or Admin. Transfers change who has campaign-wide management access; they do not change character ownership or global user roles.

The current foundation stores descriptive campaign records, memberships, invitations, and basic assigned characters. Encounters, journals, quests, maps, and detailed campaign game tools are not part of this release yet.

## Members and characters

Use personal invitations to add members. The campaign page shows joined accounts, and owners/Admins can remove them. Character lists respect the viewer's role: Players see their own assigned records; GMs see the campaign characters they may manage; Admins can manage all.

Removing a member detaches their characters from that campaign. The owner can assign a character elsewhere, and an Admin can manage assignments globally.

## Delete

Only the owning GM or an Admin can delete a campaign. Open Edit campaign, type its name in the deletion form, and submit. The campaign, memberships, and invitations are permanently deleted. Characters survive with no campaign assignment.

There is no campaign archive, trash, or undo in this foundation. Take a full instance backup before major destructive changes if you need a recovery point. A stale editing window returns a conflict rather than overwriting a newer record.
